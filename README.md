# Letermovir
This repository contains data and scripts supporting the manuscript "Computational Investigation of Novel pUL56 Ligands Using Docking and Molecular Dynamics with Preliminary Cytotoxi-city Evaluation: An Early-Stage Study".

# Contents 
'MTT+substance_database' - compound database and MTT assay results
'Molecular_docking/' - input files, poses, docking results
'Molecular_dynamics/' - input files for MD simulations (parameters, topology, scripts)
'Tanimoto script/' - script that was used for Tanimoto score calculation. 

# Code authorship and repository role
This repository contains data and computational materials supporting the results of the associated manuscript and represents the collective work of the study co-authors. The repository is maintained to ensure transparency and reproducibility of the published results.
